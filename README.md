# CourseHub — Role-Based Authentication System

CourseHub is a full-stack web application with role-based authentication for **students and teachers**.

## 🌐 Live Demo

**Frontend:**
https://coursehub-rba-frontend.vercel.app/

**Backend:**
https://course-hub-rba.vercel.app/

## ✨ Features

* User registration and login
* JWT authentication
* Role-based authorization
* Student dashboard
* Teacher dashboard
* Course management
* Protected routes
* REST API
* MongoDB database integration

## 🛠️ Tech Stack

**Frontend**

* React
* React Router
* Axios

**Backend**

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt

**Deployment**

* Vercel
* MongoDB Atlas

```text
      ↓
   Mongoose
      ↓
 MongoDB Atlas
```

## ⚙️ Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env` file in the backend with your MongoDB connection string, JWT secret, and port.
